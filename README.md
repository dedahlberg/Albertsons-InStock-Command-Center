# Albertsons In-Stock Command Center

A responsive field execution dashboard modeled on the H-E-B In-Stock Command Center format and adapted for Albertsons.

## Included views
- Overview: network in-stock, stores green, cases added, sales added, trend and priority actions
- Store Execution: store filters, in-stock gaps, OOS counts, deliveries and work-item links
- Item Tracker: status controls, 0-5 case adds, case price and automatic added-sales calculation
- Added Sales: weekly case/dollar impact and category mix
- Field Schedule: delivery, merchandising, audit and ad activity

## Data
Demo/sample data lives in `data.js`. Replace stores, items, case prices, in-stock metrics and schedules with live Albertsons data when available.

## Deploy
This is a static site. Import the repository into Vercel and deploy with no build command required.
